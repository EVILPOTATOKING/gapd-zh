# 游戏与谜题设计 · 中文阅读版

《Game & Puzzle Design》合订本(第 1–3 卷)的中英对照阅读网站。

- 目录可点击跳转到各篇文章
- 右上角或按 `L` 切换中英文;先选中一段文字再切换,会高亮对应语言的那一段

## 打开方式

**只在本机看**:双击 `index.html`。

**局域网访问**(同一 Wi-Fi 下的手机、电脑都能打开):

```bash
python3 serve.py
```

终端会打印「局域网访问」的地址,在其他设备的浏览器里打开即可。
期刊 PDF 不在仓库里,服务器默认读取本文件夹旁边的 `非常好期刊 使我设计赞赞.pdf`,
也可以用环境变量 `GAPD_PDF` 指定其他路径。

## 添加译文

在 `articles/` 下新建 `<文章编号>.js`(编号见 `assets/toc-data.js`,如 `v1n2-12`),
格式参考 `articles/v1n2-12.js`。图片放在 `articles/img/`。
